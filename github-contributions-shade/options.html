GitHub Contributions Shade

List the GitHub profiles whose contribution calendar you want re-shaded. Profiles you don't list keep GitHub's own shading, so nothing changes until you add a username and save. Saved changes show up right away in GitHub tabs opened since the extension was installed or last updated; reload any older tabs.

  • Username is the part after github.com/.
  • Each … from column is the fewest contributions in a day that get that shade of green. Days below Lightest from stay empty. The last column shows the range each shade ends up covering.
  • Choosing numbers: hover over a few busy days on the calendar to see their counts. Set Darkest around a typical busy day rather than your single busiest, and space the others evenly below it.
